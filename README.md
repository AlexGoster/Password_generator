# Password Generator

Генератор паролей с GUI на Python.

## Возможности

- Настройка длины пароля (минимум 4 символа)
- Цифры, спецсимволы, заглавные буквы — включаются отдельно
- Копирование в буфер обмена (pyperclip)
- Криптостойкая генерация через модуль `secrets`

## Запуск

```bash
pip install pyperclip
python password_gen.py
```

## Как это работает

Гарантируется наличие цифры, спецсимвола и заглавной буквы (если они включены),
остальные символы выбираются случайно и перемешиваются.
